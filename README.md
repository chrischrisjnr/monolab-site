# Automono website

The public website for **Automono**, the iPhone app that adds a black & white print of every photo you take.

- Home: https://chrischrisjnr.github.io/automono-site/
- Support: https://chrischrisjnr.github.io/automono-site/support.html
- Privacy: https://chrischrisjnr.github.io/automono-site/privacy.html

Published with GitHub Pages from the `main` branch. The source lives in the app's repository under `website/`; copy changes from there.
